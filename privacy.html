Privacy policy

Pi Drive Backup · Last updated 29 September 2026

Pi Drive Backup is a personal tool used only by its owner, @nutdevza. It is not offered to the public.

Data it accesses

Once the owner signs in with Google, it can reach the owner's own Google Drive. It uses that access only to upload, list, download and delete the owner's backup files.

Where data goes

Files travel only between the owner's Raspberry Pi and the owner's Google Drive. No copy goes to any other server. The tool has no analytics or advertising, and it sells or shares no data.

Storing sign-in tokens

The Google sign-in token is kept only in the rclone config file on the owner's Pi. The owner can revoke it at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

This tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions: open an issue at github.com/nutdevza/pi-drive-backup.
